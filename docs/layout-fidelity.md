# Верстка по скану (layout fidelity)

Три уровня (продукт):

1. **Типографика и колонка** — LLM оценивает ширину колонки, выравнивание заголовков, **высоту строк (leading)** и относительный размер кегля; кодирует классами `type-sm|md|lg`, `lh-tight|normal|loose`, `narrow`, `indent`, `shloka`, `compact`. Превью и PDF читают те же классы. Шрифт: Noto Serif Devanagari (точный металл из скана не подгружаем — приближение размером + leading).
2. **Картинки** — встроенные фигуры PDF (`data-fig`) и кропы орнаментов `<figure class="scan-crop" data-box="x,y,w,h">` → PNG в `pages/NNNN-figs/`.
3. **Чередование** — экспорт `GET .../export.pdf?mode=interleave`: страница скана, затем HTML-текст.

Уже готовые страницы Mantra Pushpam **не** переверстаются сами — нужен «Пересмотри страницу» / перегон pipeline с новым промптом.
