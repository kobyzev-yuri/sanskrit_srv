# Sanskrit SRV

Сервис оцифровки санскритских **сканов и изданий** (Devanāgarī): PDF → черновик HTML (LLM) → сверка экспертом → выверенный PDF / DOCX. От оцифровки можно открыть **перевод на русский** и **транслитерацию IAST**.

| Статус | Версия | Смысл |
|--------|--------|--------|
| Alpha | `0.1.x` | Тестовый контур; основное тестирование закрыто |
| **Beta** (сейчас) | `0.2.x` | Процесс и UI стабильны на тестовых книгах; идёт эксплуатация |
| Release 1.0 | `1.0.0` | После проверки нагрузки на нормальном сервере (не VPS ~1 ГБ) |

Сейчас: один API + один worker, SQLite. Параллелизм и запас RAM — на апгрейде хоста, см. [руководство администратора](docs/admin-guide.md) §9.

## Что умеет beta

- **Оцифровка:** PDF-скан → нарезка страниц → vision-LLM → HTML деванагари. По умолчанию Gemini через Google AI Studio; запасные OpenRouter и Claude Opus / OpenAI через ProxyAPI
- **Перевод на русский** и **транслитерация IAST** — отдельные проекты от выверенной оцифровки; правка санскрита слева пишется в оцифровку новой версией
- Редактор: скан или санскрит слева, черновик по центру (**Превью** / **Текст** / **HTML**), задание справа; шаблон скрыт за кнопкой **Шаблон**; при ручной правке рабочая панель занимает место соседних
- Согласование страниц; массовые операции (**Оцифровать / Перевести / Транслитерировать / Проверить несогласованные**) **не трогают** уже согласованные страницы
- Экспорт **PDF** и **DOCX** (текст; на оцифровке ещё «скан ‖ текст»)
- **Бэкофис:** пользователи, маршрут LLM, каталог моделей, расход по проектам и ключам
- **Кабинет (ЛК):** профиль, свои ключи / сеть, расход по своим вызовам
- Деплой: systemd (API + worker) или локальный venv / опциональный Docker

## Быстрый старт (локально)

Требования: **Python 3.12+**, ключ [Google AI Studio](https://aistudio.google.com/apikey) (`GEMINI_API_KEY`) для оцифровки и перевода. OpenRouter / ProxyAPI — опционально.

```bash
git clone git@github.com:kobyzev-yuri/sanskrit_srv.git
cd sanskrit_srv
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt

cp .env.example .env
# отредактируйте JWT_SECRET и GEMINI_API_KEY

mkdir -p data storage
cd backend
export PYTHONPATH=.
python -m app.cli init-db
python -m app.cli user-create --email admin@local --password 'changeme' --role admin --name Admin

# терминал 1 — API + UI
uvicorn app.main:app --host 0.0.0.0 --port 8000

# терминал 2 — конвейер extract + LLM
python -m app.worker
```

Откройте http://127.0.0.1:8000 → вход → загрузка PDF (роль admin).

Полные этапы, переменные окружения, бэкофис и деплой на VPS — в [руководстве администратора](docs/admin-guide.md).

## Структура репозитория

```text
sanskrit_srv/
├── README.md
├── .env.example          ← шаблон конфигурации
├── docker-compose.yml    ← опционально для локальной разработки
├── deploy/               ← systemd + remote_deploy.sh
├── backend/              ← FastAPI, worker, CLI
├── frontend/             ← статический UI (отдаёт API)
└── docs/                 ← руководства
```

Данные в рантайме (не в git): `data/` (SQLite), `storage/` (сканы, PDF), `.env`.
